# 치링 (chiring)

친구들과 행운(기운)을 주고받는 앱의 모바일 웹 프로토타입이에요. React + Vite로 만들었어요.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 터미널에 나오는 주소(보통 http://localhost:5173)를 열면 돼요.

**폰으로 보기:** https://unahynn.github.io/chiring/ (main에 올라갈 때마다 자동 배포)
PC에서는 폰 크기 프레임으로 보이고, 휴대폰에서는 화면에 꽉 차게 보여요.

## 화면 진행 상황

- [x] 온보딩: 사주 설정(사진·이름·생년월일·태어난 시간·성별) → 나의 캐해 리포트(박스 6개 + 상세 바텀시트, 만세력 보기)

- [x] 친구방 (행운방 · Lucky Talk 캐러셀 · Lucky Moments) + 하단 탭바 — 피그마 node 1870:10692
- [x] 스토리 보기 / 기운 스티커 붙이기 (Lucky Moments 카드 → 스토리)
- [x] 채팅방 → 받은 주파수 카드(앞·뒤) → 주파수 듣기 → 듣기 완료
- [x] 기운 충전 (새 디자인 · 피그마 'ZEN SERIF 영어 통일 ver.')
  - 홈: 오늘의 기운 충전(Me/Friend) + 기운 주파수 다시 듣기(Vibe 카드, 오늘 부족한 기운이 맨 앞)
  - 친구 선택 → 내용 입력 → 마음 고르기 → 필요한 기운 확인 → 기운 생성중(Light rays 셰이더)
  - 주파수 카드 선택(Lucky signal) → 메세지 입력 → 선물 완료(카드를 문지르면 참으로 바뀌어요)

## 기운 충전 메모

- **ZEN SERIF 글자**(Me, Friend, Vibe, Lucky signal, '물부처의 기운' 등)는 폰트 라이선스(수정·재배포 금지) 때문에
  폰트 파일 대신 글자 이미지로 넣었어요. 글자를 바꾸려면 `scripts/render-zen-text.py` 를 고쳐서 폰트가 설치된 컴퓨터에서 실행하세요.
- **기운 생성중** 빛은 피그마 셰이더('Light rays')를 그대로 옮긴 WebGPU 코드예요 (`src/lib/custom-effect-runtime`, `src/lib/custom-effects`).
  WebGPU가 없는 브라우저에선 같은 색의 정적인 빛 그라데이션으로 보여요.
- 필요한 기운 확인: 뒤의 빛은 그림 파일 없이 CSS로 그려요 (빛 덩어리 + 밝은 띠 + 테두리 빛이 서로 다른 박자로 일렁여요).
  다른 기운은 색만 돌려서(hue-rotate) 써요. 제목은 기운마다 '물부처 · 불부처 · 나무부처 · 금부처 · 흙부처의 기운', 부처는 위아래로 둥실둥실 떠 있어요.
- 새 카드 그림은 물 기운 3장만 있어요. 다른 기운은 예전 카드 그림을 그대로 써요.

## 온보딩

- 새 디자인(피그마 'ZEN SERIF 영어 통일 ver.' 사주 설정 · 태어난 시간 · 나의 캐해 리포트)은 어두운 화면이 기본이에요. 설정 → 화면 모드에서 라이트로 바꿀 수 있어요.
- 캐해 리포트: 타입 이름(Lemon Yellow Fire 등)은 ZEN SERIF 글자 이미지, 박스 6개는 피그마 그라데이션 + 하얀 아크릴 참(`src/assets/report`).
  만세력은 '나의 오행' 상세 시트 아래 '만세력 보기'에서 열어요.

- 앱을 처음 열면 **사주 설정 → 나의 캐해 리포트** 가 나오고, '치링 시작하기'를 누르면 홈(친구방)으로 가요.
- 입력한 정보는 이 기기(브라우저 localStorage)에 저장돼서, 다음부터는 바로 홈이 보여요.
- 다시 처음부터 보고 싶으면 주소 끝에 `?onboarding` 을 붙이면 돼요. 예: https://unahynn.github.io/chiring/?onboarding
- 오른쪽 위 톱니바퀴(설정): 화면 모드(시스템/라이트/다크), 오늘의 기운 알림, 사주 계산 기준(서울 시간 보정·야자시), 사주 정보 수정·모두 지우기
- 사주 계산(기본값): 한국 표준시에서 30분을 빼 서울 기준으로 보정하고, 밤 11~12시 출생은 일주를 그날로 보는 야자시 기준이에요. 설정에서 바꾸면 리포트가 바로 다시 계산돼요.
  음력 → 양력은 한국천문연구원 기준 `korean-lunar-calendar`, 네 기둥은 `lunar-javascript`로 계산해요.
- 리포트 문구는 `src/data/report.ts` 에서 고칠 수 있어요. `**굵게**` 는 진하게, 줄바꿈은 문단으로 보여요.

## 폴더 구조

```
src/
  components/   여러 화면에서 같이 쓰는 부분 (상태바, 하단 탭바)
  screens/      화면 단위 (FriendsRoom = 친구방, SajuSetup = 사주 설정, CharReport = 캐해 리포트)
  data/         saju.ts(오행·간지 표) · sajuCalc.ts(네 기둥 계산) · report.ts(리포트 문구) · profile.ts(내 정보 저장) · energy.ts(기운 키워드·결과 문구)
  lib/          피그마 셰이더 런타임 (기운 생성중 빛)
  assets/       피그마에서 가져온 이미지
```
